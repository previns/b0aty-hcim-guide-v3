# Guide screenshots

The section screenshots for the B0aty HCIM Guide plugin, served over
`raw.githubusercontent.com` so the plugin does not have to reach a third-party
image host.

One file per section image, named by the id the guide records for it. The
plugin verifies every file against a SHA-256 recorded in `guide.json` when the
guide is built, so replacing one here without regenerating the guide means the
plugin declines to show it rather than showing something unexpected.

This branch holds no plugin code and shares no history with `master`.
